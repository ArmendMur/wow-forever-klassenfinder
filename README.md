# ⚔️ WoW Forever – DPS Klassen-Kompass

Ein interaktives, stylisches Web-Tool für **WoW Forever**, das dir und deinen Freunden hilft, in 2 Minuten die perfekte Klasse und DPS-Spezialisierung zu finden – ohne stundenlang jeden Charakter mühsam antesten zu müssen!

---

## 🚀 Features

1. **🧭 Der DPS-Profiler (Interaktives Quiz – 100% einsteigerfreundlich)**:
   - 10 gezielte, intuitive Fragen ohne MMO-Fachchinesisch: Kampfposition, Schlag-Gefühl, Angriffs-Ablauf, Bewaffnung (Zwei Waffen, 2-Hand, Bogen, Stab, Krallen), Kampfszenario (Boss vs. Monsterwellen vs. Duelle vs. Teamplay), Rolle im Team, Schutz-Instinkt in Gefahren, gewünschter Anspruch (2 Tasten vs. Herausforderung), Fantasy-Lore und dein persönlicher Adrenalin-/Glücksmoment.
   - Gewichtete Match-Score-Berechnung mit Prozent-Ergebnis (z. B. *96% Furor-Krieger*).
   - Fokussiertes, cleanes Sieger-Profil: Archetyp-Titel, Vor- & Nachteile, 5 kampffokussierte Kennzahlen-Balken (*💥 Wuchtige Einzelschläge, ⏱️ Gleichmäßiger Dauerschaden, 🌪️ Mehrere Monster gleichzeitig, 🛡️ Hilfe & Stärkung für Freunde, ❤️ Zähigkeit*).
   - **🥈 Top 3 Alternativen**: Runner-Ups zum schnellen Quervergleich.
   - **💡 Einsteiger-Glossar**: Ausklappbare Begriffserklärungen direkt auf der Ergebnisseite.
   - **📋 Discord-Share**: Ein-Klick-Kopieren für Discord, um das Ergebnis mit der Gilde zu teilen.

2. **📜 Klassen-Katalog (Alle 20 DPS-Specs)**:
   - Alle 20 DPS-Spezialisierungen der 9 Original-Klassen (Krieger, Schurke, Magier, Hexer, Jäger, Druide, Schamane, Paladin, Priester).
   - Filter nach Nahkampf, Fernkampf, Rüstungsklasse (Platte, Kette, Leder, Stoff) und Live-Suche.
   - Klickbare Detail-Karten inklusive Rotations-Test.

3. **⚔️ Head-to-Head Duell**:
   - Wähle zwei beliebige Spezialisierungen aus und vergleiche sie direkt im Splitscreen nebeneinander.

4. **🔊 Warcraft Sound-Engine & Visuals**:
   - Eingebaute Web Audio SFX (Klicks, Schwerthiebe, Blitze, Zauber, Fanfaren) – funktioniert 100% offline ohne externe MP3-Dateien.
   - Stummschalt-Schalter im Header.
   - Dynamische Funken-Partikel im Hintergrund und originale Warcraft-Klassenfarben.

---

## 🖥️ Verwendung

Einfach die Datei `index.html` mit einem Doppelklick in einem beliebigen modernen Browser (Chrome, Firefox, Edge, Safari, Opera) öffnen – **keine Installation oder Server zwingend nötig!**

Alternativ kann bei Bedarf ein lokaler Webserver gestartet werden:
```bash
# Mit Node.js:
npx serve .

# Oder mit Python:
python -m http.server 8000
```
